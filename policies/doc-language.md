# 文档语言约定

所有生成的设计文档（SDD、TDD、SPEC、PLAN、REVIEW 等）和临时分析文档必须使用**中文**书写，除非明确要求使用英文。

## 规则

1. **文档正文** — 全部使用中文（简体），包括分析、解释、讨论、总结
2. **技术专有名词** — 保持英文不翻译，如 Agent、SDK、IPC、Operator、VLM、Zustand、shadcn
3. **代码标识符** — 保持英文（变量名、函数名、文件名、package 名）
4. **文件路径** — 保持原样（中英文混排中直接引用）
5. **文档标题** — 使用中文（如"架构概览"而非"Architecture Overview"）

## 理由

这些文档优先服务于人类阅读。LLM 对中文和英文的处理能力没有实质差异，不存在"英文对 AI 更友好"的问题。
